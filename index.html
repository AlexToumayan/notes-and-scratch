Common questions

How do I change where my notes are saved?

Open Note Storage in the sidebar and choose Local Notes or pick a folder. The new default applies to future notes and code scratches. Existing files stay in their folders.

How does Code Trace work?

Open a Python, JavaScript, Java, C, or C++ file, open Code Trace, and select Run Trace. The app sends the code in that file to Python Tutor to run it and show each step. What if dictation won’t start?

Check that Notes & Scratch has microphone access in your device’s privacy settings. Dictation uses Apple’s on-device speech recognition on supported devices, and Apple may need to download a speech model the first time you use it.
